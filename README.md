# BXTpa

BXTpa, Minecraft sunucuları için sade, hızlı ve tamamen Türkçe bir TPA eklentisidir.

## Komutlar

- `/tpa <oyuncu>` — Oyuncuya ışınlanma isteği gönderir.
- `/tphere <oyuncu>` — Oyuncunun senin yanına gelmesini ister.
- `/tpaccept` — Gelen isteği kabul eder.
- `/tpdeny` — Gelen isteği reddeder.

Warp, Home, Spawn, RTP, Back ve benzeri sistemler BXTpa'dan çıkarılmıştır. Eklenti yalnızca TPA sistemi üzerine kuruludur.

## Özellikler

- Tamamen Türkçe kullanıcı mesajları
- TPA ve TPHERE istekleri
- Kabul / reddet sistemi
- İstek zaman aşımı
- Işınlanma bekleme süresi
- Hareket edince ışınlanmayı iptal etme
- Oyuncu çevrimdışı olduğunda güvenli istek temizleme
- Özelleştirilebilir `config.yml`
- Türkçe `messages`/`language` dosyası
- Logo dahil proje yapısı
- Spigot ve Paper odaklı yapı

## English Description

BXTpa is a lightweight and customizable TPA (Teleport Request) plugin designed for Minecraft servers. It provides a clean, modern, and user-friendly teleport request system.

### Features

- `/tpa <player>` — Send a teleport request
- `/tphere <player>` — Request a player to teleport to you
- `/tpaccept` — Accept a request
- `/tpdeny` — Deny a request
- Clickable ACCEPT and DENY buttons — accept or deny requests without typing commands
- 5-second teleport countdown (5 → 4 → 3 → 2 → 1); moving during the countdown cancels the teleport
- Fully customizable messages and colors
- Turkish message support
- Configurable settings
- Lightweight and performance-friendly
- Spigot & Paper compatible

BXTpa focuses only on teleport requests, without unnecessary /home, /warp, /spawn, or other unrelated commands.

Fast. Simple. Customizable. BXTpa.
